# InvestAware UK — Website V1

A clean, modern, information-only educational website about investing, pensions and long-term
financial planning. Built as **plain HTML, CSS and JavaScript** — no build step, no framework,
no database. Open `index.html` in a browser to view it locally, or upload the whole folder to any
static host.

## The single most important file: `assets/js/config.js`

Figures that change — ISA allowance, LISA allowance and bonus, pension annual allowance,
pension access age — are defined in `config.js`, and any element marked `data-fig="ISA_ALLOWANCE"`
is filled from it at runtime.

**Belt-and-braces:** each of those values is *also* written as literal fallback text inside its
element (e.g. `<strong data-fig="ISA_ALLOWANCE" data-money>£20,000</strong>`) so nothing ever
renders blank if the script or config fails to load. When you update a figure, change it in
**both** `config.js` and the inline fallback so they stay in step. (The chart assumptions below
have no inline fallback — they're only used by JS, which the charts need anyway.)

The same file holds the **illustrative assumptions** used to draw the charts (growth rate,
inflation, contribution amounts, fee levels). These are round teaching numbers, not forecasts.
Change them in one place and every chart updates.

> **Review the figures each tax year** against current GOV.UK / HMRC values, and update
> `taxYear` and `lastReviewed` at the top of `config.js`. The footer and every "Last reviewed"
> line read from there.

## Editing or adding content

- **Header & footer** are generated by `main.js`, so there's only one place to edit navigation.
- **To add a page:** copy an existing page in the relevant section as a template. Keep the
  `<body data-base=".." data-section="investing">` attributes (`data-base` is `""` at the site
  root and `".."` one level deep; `data-section` highlights the right nav item). Set a unique
  `<title>` and `<meta name="description">`. Then add a link to it from the section's landing page.
- **Charts:** add `<canvas id="my-id" data-chart="compoundCurve"></canvas>` and include, before
  `main.js`, `../assets/js/vendor/chart.umd.js` and `../assets/js/charts.js`. Available charts:
  `compoundCurve`, `startingEarlier`, `feeDrag`, `inflationErosion`, `marketShape`, `pensionBuild`.

## Hosting & clean URLs

The site works as-is on any static host (Netlify, Cloudflare Pages, GitHub Pages, S3, etc.) and
when opened directly from disk. Links use relative `.html` paths so both work.

To get "clean" URLs without the `.html` (e.g. `/investing/compound-growth`), enable your host's
pretty-URL / rewrite option — most static hosts offer this. No code changes are needed.

## Design & principles baked in

- Calm, editorial, non-fintech aesthetic; strong typography; generous whitespace; mobile-first.
- Every page answers **what is it? / how does it work? / why does it matter?**
- The recurring ideas — compounding, time in the market, buy the haystack, costs, behaviour,
  simplicity — reappear across the site, always with the reasoning, never as bare slogans.
- Education, not advice: a persistent footer disclaimer, illustration notices on every chart,
  and no product or provider recommendations anywhere.

## Not in V1 (by design)

No accounts, calculators, quizzes, sign-ups, contact forms, affiliate links or calls to action.
The content is the product. The architecture leaves room to add tools later without rework.
